# SIS Project — Checkpoint 1: Text Analyzer

Приложение для анализа текстовых задач в оперативной памяти. Для каждой задачи вычисляется количество слов, символов, гласных букв и находится самое длинное слово.

## Жизненный цикл задачи (Task Lifecycle)

Каждая задача проходит через строгий жизненный цикл, представленный типом `State`:

1. **`Pending`** — Задача успешно прошла валидацию, создана и сохранена в памяти, но ее обработка еще не начиналась (`Result == nil`).
2. **`Processing`** — Задача находится в процессе выполнения бизнес-логики подсчета статистики.
3. **`Completed`** — Задача успешно обработана, результат (`Result`) сформирован и привязан к задаче.

# SIS Project - Checkpoint 2: Concurrent Text Analyzer

Приложение для асинхронного анализа текстовых задач с использованием пула воркеров (Worker Pool) и ограниченной очереди в оперативной памяти.

## 1. Назначение и логика обработки
Приложение принимает текстовые строки и вычисляет для каждой задачи:
* количество слов (`WordCount`);
* количество символов/рун (`CharCount`);
* количество русских и английских гласных (`VowelCount`);
* самое длинное слово без учета знаков препинания (`LongestWord`).
